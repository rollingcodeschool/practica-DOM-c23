# Práctica DOM y BOM - JavaScript

Este proyecto es una práctica enfocada en la manipulación del **Document Object Model (DOM)** y **Browser Object Model (BOM)** utilizando JavaScript vanilla. El objetivo es interactuar con elementos HTML, gestionar eventos y actualizar la interfaz de usuario de forma dinámica.

## 🚀 Características

- Selección de elementos del DOM (ID, clases, selectores).
- Creación y eliminación dinámica de nodos.
- Manejo de eventos (click, submit, input, etc.).
- Modificación de estilos y atributos CSS a través de JS.
- Validación de formularios básica.
- Uso de setTimeout y setInterval

## 🛠️ Tecnologías utilizadas

- **HTML5**: Estructura semántica.
- **CSS3**: Estilos y diseño responsivo.
- **JavaScript (ES6+)**: Lógica de manipulación del DOM.

## 📂 Estructura del Proyecto

```bash
10-practicaDOM/
├── index.html          # Archivo principal HTML
├── css/
│   └── styles.css      # Hoja de estilos
├── js/
│   └── app.js          # Lógica de manipulación del DOM y BOM
└── README.md           # Documentación del proyecto
```

## 🔧 Instalación y Uso

1. Clona el repositorio o descarga los archivos.
2. Abre el archivo `index.html` en tu navegador preferido.
3. ¡Interactúa con la interfaz para ver los cambios en el DOM en tiempo real!

## 📝 Notas de Aprendizaje

Durante esta práctica se reforzaron conceptos como:
- La diferencia entre `textContent` e `innerHTML`.
- El uso de `addEventListener`.
- Recorrido del DOM (Parent, Child).
- Métodos del BOM (setInterval, setTimeout).
